# DE os

Ik heb nog geen naam voor dit project, maar dit wordt een bureaublad omgeving voor de
raspberry pi, hiermee kun je met controller je apps selecteren of gamen met die controller
een soort game console achtig apparaatje, maar dan met de bureaublad omgeving van mij.

Het gaat mij meer om de front end dan de back end, als die ook echt werk is altijd leuk maar
niet mijn prioriteit.

Ik had altijd mijn eigen game console willen maken, en vooral met een raspberry pi willen gaan 
spelen, meer aan de software kant.

Hiermee hoop ik te leren hoe ik alle apps kan onder 1 DE kan zetten, via js css en html.

Mijn werk proces is zoals als altijd:
    1. kijken wat er gedaan moet worden.
    2. bezig gaan met die opdracht.
    3. zelf testen, De projecten zijn altijd klein.
    4. (pas bij grote project) andere mensen vragen of dit goed is.
